# Honor Pad 8 Debloater: the catalogue of known apps and services.
#
# The app shows every entry here with a Leave / Hide / Remove choice, and the tablet scan script
# (tool/scan_tablet.py) uses it to describe what it finds. The second field is the default:
#   remove = hidden, with its data wiped and its Play Store updates stripped
#   hide   = hidden, data kept (choosing Leave later restores it as it was)
#   leave  = offered in the app, but left alone until you choose
# In a "lock" group the default is lock or leave. ("on" means hide and "off" means leave.)
#
# Format (one item per line, fields separated by "|"):
#   == group-id | mode | Group title | What the group is
#   package.name | default | Display name | One-line description
# Modes: hide = a Leave / Hide / Remove choice; lock = the choice locks its permissions off;
#        core = never hidden by the app, whatever the lists say;
#        keep = best left alone (things depend on them); not shown in the app, listed so the scan script can label them.
# Lines starting with # are comments.
